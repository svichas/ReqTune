Fine-tune every header.

Set, append or remove each one, or untick it to pause it. Change responses too, and limit a group to Fetch/XHR or POST requests.

Match URLs with wildcards or regex.

A * matches any characters, and in a host it never crosses a /. Start with regex: when wildcards aren't enough.

Pattern
Matches
example.comEvery URL on the site
*.example.comThe site and all subdomains
api.example.com/v1/*Everything under /v1/
localhost:3000Only port 3000
regex:^https://api\.A regular expression
/graphqlThat path on any host
